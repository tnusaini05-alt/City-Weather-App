# City-Weather-App

Live weather app for any city with temperature, humidity, wind details, and current location support.

## Features
- Search weather by city name.
- Get weather for your current location.
- Shows temperature, feels like, humidity, wind speed, and weather description.
- Dynamic weather icon.
- Responsive and simple UI.

## Built With
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Demo
[Live Demo](https://tnusaini05-alt.github.io/City-Weather-App/)

## How to Use
1. Type a city name in the search box.
2. Click **Search**.
3. Or click **Use My Location** to get weather for your current place.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/tnusaini05-alt/City-Weather-App.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
